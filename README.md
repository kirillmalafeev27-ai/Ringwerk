# RINGWERK

Бодрая 2D-аркада для тренировки немецких Wechselpräpositionen. Три кольца непрерывно вращаются, неподвижные угрозы пересекают траекторию игрока, а правильный ответ открывает одно тактическое действие. Мир не ставится на паузу во время вопроса.

## Цель

Активируйте узлы A, B и C в любом порядке, учитывая пользу и цену каждого протокола, затем доберитесь с внутреннего кольца до центрального выхода.

## Управление

- `1–3` — выбрать форму ответа.
- `A / D` — шаг по кольцу.
- `W / S` — перейти на внешнее или внутреннее кольцо.
- `Space` — зацепиться за ближайшую спицу или отпустить её.
- `Z / X` — применить бонус из одного из двух слотов.
- `P` — включить или выключить звук.

## Локальный запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Проверка

```bash
npm run lint
npm test
npm run build
```
