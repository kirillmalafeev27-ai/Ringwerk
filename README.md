# RINGWERK

Бодрая 2D-аркада для тренировки немецких Wechselpräpositionen. Три кольца непрерывно вращаются, неподвижные угрозы пересекают траекторию игрока, а правильный ответ сохраняет остаток быстро сгорающего импульса. Мир не ставится на паузу ни во время вопроса, ни после ответа.

## Цель

Активируйте узлы A, B и C в любом порядке, учитывая пользу и цену каждого протокола, затем доберитесь с внутреннего кольца до центрального выхода.

## Управление

- `1–4` — выбрать форму ответа.
- `A / D` — шаг по кольцу.
- `W / S` — перейти на внешнее или внутреннее кольцо.
- `Space` — зацепиться за ближайшую спицу или отпустить её.
- `Q` — прыжок между крайними кольцами при импульсе от 80%.
- `Z / X` — применить бонус из одного из двух слотов.
- `P` — включить или выключить звук.

## Локальный запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Вопросный поток

Клиент держит очередь из синтетических пакетов по 8 вопросов и начинает фоновое пополнение при остатке меньше 3. Последние 60 формулировок передаются в `exclude`; история дедупликации хранит 80 вопросов. Если сервер, сеть или модель недоступны, игра без ожидания использует встроенный резерв. Неправильно решённый вопрос возвращается в хвост очереди.

AITunnel вызывается только на сервере. Для локального production-режима скопируйте `.env.example` в `.env.local` и задайте `AITUNNEL_API_KEY`. `/api/questions/status` показывает только готовность серверной конфигурации, не раскрывая ключ, провайдера или модель.

## Northflank

Репозиторий готов к Combined Service из корневого `Dockerfile`:

- build type: `Dockerfile`, context `/`;
- public HTTP port: `3000`;
- readiness/liveness: `GET /healthz` на порту `3000`;
- runtime secret: `AITUNNEL_API_KEY`;
- необязательные runtime variables перечислены в `.env.example`;
- одна реплика для in-memory кэша пакетов (при масштабировании нужен общий Redis-lock/cache).

Контейнер собирает отдельный vinext standalone runtime с `DEPLOY_TARGET=node`, слушает `0.0.0.0:$PORT` и не содержит `.env`-файлы. Обычная сборка без `DEPLOY_TARGET=node` остаётся Cloudflare/Sites-сборкой.
